# Editorial status of the rebuilt bank

All 900 entries are unreviewed drafts. Automated validation verifies schema, unique IDs and exact transcripts, four distinct answer options, the declared correct option, word limits, and distribution targets. It does not establish legal correctness or substantive originality.

Counts: 315 easy, 360 medium, 225 hard; 162 No objection answers (18%); largest concept is hearsay with 180 entries (20%).

The bank reuses instructional structures across varied fictional disputes. The dialogue pass removes the repeated introductory exchange, moves case facts into the context, and uses clearer spoken questions and answers. Repeated doctrinal structures still remain. Distinct text and factual context do not establish 900 independently developed legal fact patterns. Substantive diversity remains an editorial acceptance gap. Difficulty labels also need calibration by an evidence-law reviewer.

Before public release, revise repetitive decisive questions and answers, check each scenario for exactly one defensible best answer, verify each FRE citation and exception prerequisite, and approve entries individually through `npm run content:review`. Production excludes every unreviewed entry even when ALLOW_UNREVIEWED=true.

The working application and automated tests are separate achievements from legal-content approval. This rebuild should be used as a development/demo project until editorial work is complete.

The October bonus archive adds 155 separately authored scenarios across 31 dockets. These also remain unreviewed; publication requires human approval. Daily IDs, answer keys, and schedule assignments are preserved by the readability pass.
