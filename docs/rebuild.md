# Objectle recovery and preservation

Rebuilt after an unpublished cloud workspace was lost. Source control is the durable handoff: each implementation area is committed locally, and the completed project is backed up to the connected GitHub repository when access allows.

The application is a daily five-question Federal Rules of Evidence game. Node 24, React/Vite/Tailwind, Express, SQLite, Zod, Vitest and Playwright. Server calendar America/New_York, seeded 180-day schedule without repeats, 900 unreviewed fictional content entries. Production must exclude unreviewed entries. Human legal review and content originality are separate from structural validation.

Do not confuse saved environment scripts with a backup of source files. Verify a remote Git commit before relying on GitHub recovery.
